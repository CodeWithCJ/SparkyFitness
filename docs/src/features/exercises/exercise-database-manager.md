# Exercise Database Manager

This page will explain how to use the Exercise Database Manager in SparkyFitness.
## Demonstration videos

Each exercise can carry a video link, usually a short YouTube clip showing good form. Add it in the **Video link** field when you create or edit an exercise, on the web or in the mobile app. Leave it blank to remove it.

- **Web:** YouTube links play inline in the exercise form and in the **Play Instructions** view. Other links open in a new tab.
- **Mobile:** the exercise's **How to** tab shows the video's thumbnail; tap it to open the clip (in the YouTube app when installed). During a live workout, the expanded exercise card shows a **Demo** button.

Any `http` or `https` link works. YouTube watch, `youtu.be`, Shorts and embed links all get a preview, and a `t=` start time is kept.
