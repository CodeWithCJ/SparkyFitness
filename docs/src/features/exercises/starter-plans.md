# Starter Plans

Starter plans are ready-made strength plans you can add in one tap. Each one becomes your own presets plus a workout plan, so you can edit, rename or delete any part of it afterwards.

| Plan                   | Workouts in the rotation              | Good for               |
| :--------------------- | :------------------------------------ | :--------------------- |
| **Full Body**          | Full Body A → Full Body B             | 2 to 3 days a week     |
| **Upper / Lower**      | Upper A → Lower A → Upper B → Lower B | 4 days a week          |
| **Push / Pull / Legs** | Push → Pull → Legs                    | 3 or 6 days a week     |
| **5×5**                | 5×5 A → 5×5 B                         | 3 days a week, barbell |

## Adding one

- **Web:** Exercises → Workout Plans → **Starter plans** → **Add plan**.
- **Mobile app:** Library → Workout plans → scroll to **Starter plans** → **Add plan**.

The plan's exercises are added to your exercise library if they aren't there yet. The plan starts today and is switched on.

## How it runs

Starter plans are **sequential** plans, a rotation: the next workout is always the next one you haven't done, whatever the day. Miss a day and nothing is skipped; train twice in a row and you simply move on.

## Weights and progression

The presets start without weights. Log your first session with weights you can manage and progression takes over from there:

- **5×5** and the main lifts in **Full Body** use **Fixed Target**: once every set hits 5 reps, the next workout adds 2.5 kg (5 kg on deadlifts).
- Everything else uses **Double Progression** over a rep range, such as 6 to 8 or 10 to 15: the weight goes up once every set reaches the top of the range.
- After three missed sessions in a row at the same weight, the next workout suggests a deload of about 10%.

See [Progression & Per-Set Ramp](./progression-and-per-set-ramp) for the details.

## Older servers

The mobile app only shows starter plans when your server offers them. With an older server the section is hidden; update the server to get them.
