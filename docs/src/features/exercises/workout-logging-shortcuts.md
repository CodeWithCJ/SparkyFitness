# Workout Logging Shortcuts

These shortcuts are in the mobile app's active workout screen.

## Swipe a set

- **Swipe left** on a set to show **Delete**. After you delete a set, a message offers **Tap to undo**. Tapping it puts the set back in the same place with the same weight, reps and type. Deleting an exercise's only set still asks first, because it removes the exercise.
- **Swipe right** on a set to show **Copy**. A copy of the set goes straight after it with the same type, weight, reps and rest, ready to do. It does not copy the original's notes, RPE or done mark.

## Flash the screen when rest ends

In **Settings → Workout**, turn on **Flash the screen when rest ends**. When a rest timer runs out with the app open, the workout screen pulses briefly in the accent colour. This helps when your phone is muted or you're wearing headphones. Skipping a rest or finishing a set early does not flash.

With **Reduce Motion** turned on in your phone's accessibility settings, the flash is a single soft pulse. It is off by default.
