# Cloud Hosting

If you are not a technical user, or would rather not run SparkyFitness on your
own server, you can deploy a hosted instance with one of the providers below.
You do not need to set up Docker or a server yourself.

::: info
These are independent third-party services. Before signing up, review each
provider's pricing, privacy policy, and backup options to find the best fit.
:::
