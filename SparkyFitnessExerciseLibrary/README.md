# SparkyFitness Exercise Library 🏋️

Exercise catalog, media assets, and multilingual instruction database for SparkyFitness.

## Structure

- **`exercises/<numeric_id>_<slug>/`** — One folder per exercise containing `exercise.json` and its media (`.mp4`, `.gif`, `.webp`).
- **`locales/<lang>/exercises.json`** — Translation dictionaries synced with Weblate.
- **`taxonomy/`** — Standard muscle, equipment, and modality lists.
- **`schema/`** — JSON schema validation rules.
- **`dist/exercises.json`** — Compiled catalog generated by the build script.

## Example Exercise

```text
exercises/00025_barbell_bench_press/
├── exercise.json
├── 00025_barbell_bench_press.mp4
├── 00025_barbell_bench_press.gif
└── 00025_barbell_bench_press.webp
```

**`exercise.json`:**
```json
{
  "id": "00025_barbell_bench_press",
  "numeric_id": "00025",
  "slug": "barbell_bench_press",
  "name": "Barbell Bench Press",
  "aliases": ["Flat Bench Press"],
  "taxonomy": {
    "modality": "weight_reps",
    "category": "chest",
    "body_part": "chest",
    "mechanic": "compound",
    "force": "push",
    "level": "intermediate",
    "equipment": "barbell",
    "primary_muscles": ["chest"],
    "secondary_muscles": ["shoulders", "triceps"]
  },
  "biomechanics": {
    "laterality": "bilateral",
    "movement_plane": "sagittal",
    "default_tempo": "2-0-1-0",
    "demonstration_reps": 2
  },
  "steps": [
    "Lie flat on the bench with your eyes directly under the bar.",
    "Grip the barbell slightly wider than shoulder-width apart.",
    "Unrack and lower slowly to mid-chest with elbows tucked.",
    "Press the bar back up to the starting position."
  ],
  "coaching_cues": [
    "Keep shoulder blades retracted and depressed into the bench",
    "Maintain five points of contact: head, upper back, glutes, and both feet"
  ]
}
```
*(Note: The `"media"` block in `exercise.json` is completely **optional**. Media files are auto-discovered by convention from the exercise folder during build!)*

## Media Standards & Auto-Discovery

Media files are **auto-discovered by filename convention** inside each exercise folder:

| Asset Type | File Naming Convention | Description |
| :--- | :--- | :--- |
| **Vertical Video (9:16)** | `<id>_9_16.mp4` | 720×1280 portrait loop (ideal for mobile full-screen / tutorial) |
| **Horizontal Video (16:9)**| `<id>_16_9.mp4` | 1280×720 or 720×404 widescreen (ideal for web, desktop & compact logger) |
| **Single / Default Video** | `<id>.mp4` | Generic MP4 video (used if only one orientation is available) |
| **Thumbnail Image** | `<id>.webp` (or `.jpg`, `.png`) | Card thumbnail image (~20–40 KB) |
| **Animated GIF** | `<id>.gif` | Low-bandwidth preview loop (~1.5–3.0 MB) |
| **Static Diagram** | `<id>.webp` (or `.png`, `.jpg`) | Fallback for exercises without video (stretches, mobility) |

### Video Encoding Guidelines
- **Codec:** H.264 (`libx264`)
- **Audio:** Silent (`-an`) for smooth seamless looping
- **Optimization:** Web-ready `+faststart`
- **Target Size:** ~0.5 MB to 1.5 MB (hard cap 2.5 MB)
- **Duration:** 5 to 15 seconds (shows 1–2 complete repetitions)

## Media Optimization CLI

Whenever you add or update raw video files, run the automated media optimizer:

```bash
# 1. Automatically compress oversized videos, strip audio, and generate missing .webp / .gif
npm run optimize-media

# 2. Extract 4 candidate thumbnail frames across the rep cycle to pick the best action frame
npm run optimize-media -- --candidates 00857

# 3. Force re-encoding of all media
npm run optimize-media -- --force
```

*(If you wish to specify an exact timestamp for the thumbnail in `exercise.json`, you can optionally add `"media": { "thumbnail_timestamp": 3.0 }`).*

## Taxonomy Reference

`exercise.json` enforces canonical taxonomy values matching the SparkyFitness ecosystem:

* **Modality (`taxonomy.modality`):**  
  `weight_reps` · `bodyweight_reps` · `reps_only` · `weight_duration` · `weight_distance` · `duration` · `duration_distance`
* **Equipment (`taxonomy.equipment`):**  
  `barbell` · `dumbbell` · `kettlebells` · `cable` · `machine` · `bands` · `body only` · `medicine ball` · `exercise ball` · `foam roll` · `e-z curl bar` · `other`
* **Muscles (`primary_muscles` / `secondary_muscles`):**  
  `abdominals` · `abductors` · `adductors` · `biceps` · `calves` · `chest` · `forearms` · `glutes` · `hamstrings` · `lats` · `lower back` · `middle back` · `neck` · `quadriceps` · `shoulders` · `traps` · `triceps`
* **Mechanic & Force:**  
  `mechanic`: `compound` · `isolation` · `other`  
  `force`: `push` · `pull` · `static` · `other`  
  `level`: `beginner` · `intermediate` · `advanced`

*(See the `taxonomy/` folder for complete schema definitions).*

## Contributing an Exercise

Follow these step-by-step instructions to add a new exercise:

### 1. Choose the 5-Digit ID & Folder Name
* Exercises use a **zero-padded 5-digit ID** and snake_case slug: `exercises/<numeric_id>_<slug>/` (e.g., `exercises/01004_squat_band/`).
* Check existing IDs in `dist/exercises.json` or assign the next available sequential number.

### 2. Create `exercise.json`
* Copy an existing `exercise.json` (like the Barbell Bench Press example above).
* Fill in the canonical taxonomy, biomechanics, and clear English **`steps`** (which serve as the source of truth for translations).
* **You do not need to write a `"media"` block** — media files are auto-discovered from the folder.

### 3. Add Media & Auto-Optimize
* Drop your video (`.mp4`) into the exercise folder following the naming convention:
  * `<id>_9_16.mp4` for vertical video, or `<id>_16_9.mp4` for horizontal video (or both!).
  * Or `<id>.mp4` if providing a single default video demonstration.
* Run the media optimizer commands:
  ```bash
  # Optimize only missing or unoptimized media across all exercises:
  pnpm media

  # Force re-encode all exercises:
  pnpm media force-all

  # Force re-encode only one specific exercise:
  pnpm media force 00857

  # Preview candidate thumbnail frames to pick the best action frame timestamp:
  pnpm media candidates 00857
  ```
  *This automatically compresses videos to ≤ 1.5 MB, mutes audio (`-an`), adds `+faststart`, and generates:*
  * `<id>_thumb.webp`: Lightweight static card thumbnail (360x640 / 640x360, ~15–25 KB).
  * `<id>_9_16.webp` / `<id>_16_9.webp` / `<id>.webp`: Full-duration animated WebP preview loops (~160–460 KB) with 24-bit true color for smooth mobile & web playback and compact offline caching.

### 4. Validate and Build
Before committing, run:
```bash
pnpm validate   # Must pass with zero errors
pnpm build      # Updates dist/exercises.json and locales/en/exercises.json
```

### 5. What to Commit & Submit in PR
Git automatically ignores `.mp4` video files to prevent repository bloat. In your git commit, include:
* ✅ `exercises/<id>_<slug>/exercise.json`
* ✅ `exercises/<id>_<slug>/<id>_thumb.webp` (static card thumbnail)
* ✅ `exercises/<id>_<slug>/<id>_9_16.webp` / `<id>_16_9.webp` / `<id>.webp` (animated WebP loops)
* ✅ `dist/exercises.json` (auto-updated by build)
* ✅ `locales/en/exercises.json` (auto-updated by build)
* 📎 **Attach your compressed `.mp4` video directly to your GitHub PR description** (drag-and-drop into GitHub PR comments). Maintainers will upload it to the SparkyFitness media CDN.
