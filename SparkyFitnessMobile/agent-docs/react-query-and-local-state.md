# React Query And Local State: details

Longer notes for the "React Query And Local State" section of [`SparkyFitnessMobile/AGENTS.md`](../AGENTS.md). Each one has a one-line link there.

## App-local toggles (appPreferencesStore)

- App-local toggles live in `stores/appPreferencesStore.ts` (Zustand `persist`, single AsyncStorage key `@SparkyFitness/app-preferences`): haptics, sounds, notifications, hydration/fasting card visibility, Ask Sparky and progress photos card visibility, the Liquid Glass tab bar opt-in, the active-workout metric column, the default rest period (`defaultRestSec`, edited in `WorkoutSettingsScreen`), mood check-in reminders (`checkinRemindersEnabled`, `checkinReminderTimes`, edited in `NotificationSettingsScreen` and offered once after the first check-in), hydration reminders (`waterReminderEnabled`, `waterReminderIntervalHours`, `waterReminderWindowStart` / `waterReminderWindowEnd`, edited in `NotificationSettingsScreen`), the Health Trends layout (`healthTrendOrder` + `hiddenHealthTrends`, edited in `HealthTrendsSettingsScreen`), the Reports layout (`reportOrder`, `hiddenReports`, `reportDefaultRange`, `hiddenReportSections`, `reportNutrientOrder`, `shownReportNutrients`, edited in `ReportsSettingsScreen`), the Compare report's recent questions (`compareRecentQuestions`, newest first, max 5, written by `CompareReportScreen` and read through `knownCompareQuestions`, which drops any a later build no longer knows), and the Apple Watch layout (`watchPageOrder` + `hiddenWatchPages`, the Goals page's `watchNutrientOrder` + `shownWatchNutrients`, and `watchSetInputStyle`, all edited in `WatchSettingsScreen`). The Health Trends pair is written through the single `setHealthTrendLayout(order, hiddenKeys)` setter rather than one per field, because one drag changes order and visibility together; a saved order is reconciled against `constants/healthTrends.ts` by `resolveHealthTrendOrder`, so registering a new graph needs no `STORE_VERSION` bump. Consume via selectors (`useAppPreferencesStore((s) => s.hapticsEnabled)`) plus generated setters; non-React code reads current values through helpers like `getDefaultRestSec()`. A legacy-aware storage adapter migrates the old per-key `@HealthConnect:*` values once. These preferences never sync to the server.
