# Quick Routing: details

Longer notes for the "Quick Routing" section of [`SparkyFitnessMobile/AGENTS.md`](../AGENTS.md). Each one has a one-line link there.

## Heart rate zones

- Heart rate zones: Settings → Heart Rate Zones (`HeartRateZonesSettingsScreen`, root-stack `HeartRateZonesSettings`) edits `GET`/`PUT /api/v2/heart-rate-zones` through `useHeartRateZones` / `useUpdateHeartRateZones` (`heartRateZonesQueryKey`; the server returns the saved settings plus the five resolved zones, so the screen, `useSuggestedRanges` and the chart label all read one response). The zone maths is shared (`heartRateZones.ts`), never re-derived here. The Heart Rate report (`HeartRateReportScreen`) lists the person's zones (five, or four tiers when `settings.display_zones` is 4) with their bpm ranges through `components/reports/HeartRateZoneRanges.tsx`, says where they come from and links to the settings screen; it shows `defaultHeartRateZones()` until the query loads. The report is daily summaries only, so it has no time in zone. Folding into tiers is only `heartRateDisplayBands` from shared, driven by the **Show** setting; never hard-code bpm. `HeartRateZones` (the zone bars on `CardioSessionScreen` and `WorkoutDetailScreen`) shows the method each stored breakdown was worked out with (`HeartRateZoneRow.method`, `utils/heartRateZoneLabels.ts`); changing settings does not recompute past workouts. On iOS 27, **Use Apple Health zones** (`services/appleHeartZones.ts`, native `modules/apple-heart-zones`) reads `HKHealthStore.preferredWorkoutZoneConfiguration` and fills the form as custom floors through shared `floorsFromAppleHeartRateZones` (zone 1 with no lower bound starts at 30 bpm; anything other than five zones is ignored). It does not save by itself, does not change max heart rate, and fills an empty resting heart rate from HealthKit. The new native module needs `npx expo prebuild --clean` and a new build before the button appears. On iOS 27 / watchOS 27, a finished workout's heart-rate zone group is stored as device zones (`bucketsFromAppleWorkoutZones`) instead of the server recomputing them, including for watch workouts, watch runs and phone GPS recordings; imported HealthKit workouts are read by `heartRateZonesForWorkouts`.
